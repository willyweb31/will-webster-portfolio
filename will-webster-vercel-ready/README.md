# Will Webster Portfolio

A standard Next.js portfolio prepared for deployment on Vercel.

## Deploy with Vercel

1. Create a new GitHub repository and upload all files from this folder.
2. Open https://vercel.com/new and import that repository.
3. Keep the automatically detected Next.js settings and select Deploy.

## Run locally

Install dependencies with `pnpm install`, then start the site with `pnpm dev`.
